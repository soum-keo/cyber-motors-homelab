# Cyber Motors Homelab

A simulated small-business IT environment designed to practice and demonstrate hands-on skills in systems administration via Linux & Microsoft AD, networking, virtualization, and network security.

## Overview

This project simulates the IT infrastructure of **Cyber Motors**, a fictional automotive dealership.

The goal of this homelab is to build and administer a realistic small-business environment, and to develop practical skills that can be applied to IT infrastructure, network/cloud engineering, and cybersecurity roles.

## Objectives

* Build and manage virtualized infrastructure
* Practice Linux and Windows system administration
* Develop networking and infrastructure skills
* Implement basic security practices
* Practice troubleshooting and documentation
* Learn how IT systems work together in a business environment

## Current Environment

| Component     | Purpose                               |
| ------------- | ------------------------------------- |
| Proxmox VE    | Virtualization platform               |
| Ubuntu Server | Linux infrastructure server           |
| Windows       | Client/server administration practice |
